This topic describes how to download the .NET sample app and prepare
to deploy the app to {{ product_full }}.

## Overview

In this tutorial, you download an existing .NET app that is ready
to deploy.

## Download the .NET sample app

To download the .NET sample app, do the following:

1. Run the following command:

        git clone https://github.com/kathap/dotnet-core-hello-world

1. Navigate to the app directory:

        cd dotnet-core-hello-world
